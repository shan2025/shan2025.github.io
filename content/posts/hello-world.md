Welcome to my corner of the internet! 👋

I've wanted a place to collect my projects and write about what I'm learning for a while, so here it is.

## What I'll write about

- **AI products**: building chat assistants with retrieval-augmented generation, and what actually works in practice.
- **Machine learning**: notes from projects like predicting rocket landings and scoring crypto wallet risk.
- **Shipping things**: the small lessons that come from taking an idea all the way to something people use.

## How this site works

The site is built with [Next.js](https://nextjs.org) and exported as plain static files, which GitHub Pages hosts for free. Every post is a Markdown file in the `content/posts` folder, so writing a new one is as simple as:

```md
---
title: My new post
date: 2026-11-01
excerpt: One sentence that shows up in the post list.
tags: [ai, notes]
---

Write anything here in Markdown.
```

Push it to GitHub and the site rebuilds itself in about a minute.
